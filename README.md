# Masud AI - GitHub Pages

Upload these files to a public GitHub repository and enable GitHub Pages.

Files:
- index.html
- terms.html
- privacy.html

After publishing, the URLs will be:
- https://YOUR_USERNAME.github.io/REPOSITORY_NAME/
- https://YOUR_USERNAME.github.io/REPOSITORY_NAME/terms.html
- https://YOUR_USERNAME.github.io/REPOSITORY_NAME/privacy.html

Use the last two URLs in TikTok Developer:
Terms of Service URL -> terms.html
Privacy Policy URL -> privacy.html

Do NOT put the TikTok OAuth callback URL in these fields.
